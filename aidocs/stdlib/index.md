# Standard Library

Neon.js comes with a standard library of useful modules that you can use in your projects.

## Available Modules

- **[NodeSupport](./nodesupport.md):** A module for creating tree-like structures with parent-child relationships.
- **[CustomEventSupport](./customeventsupport.md):** A module for adding custom event handling to any class.
- **[BubblingSupport](./bubblingsupport.md):** A module that adds event bubbling capabilities to classes that also use `NodeSupport` and `CustomEventSupport`.
- **[Widget](./widget.md):** A base class for creating UI widgets. It includes `NodeSupport` and `CustomEventSupport` and has a dependency on jQuery.
